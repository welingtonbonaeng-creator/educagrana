# EducaGrana

Protótipo de front-end do **EducaGrana**, app de educação financeira gamificada.
Projeto da disciplina Práticas Extensionistas Integradoras II, Engenharia de Software, Universidade de Vassouras (2026).

Feito com HTML, CSS e JavaScript puros, sem framework. Os dados ficam salvos no navegador (localStorage).

**Simulação educativa:** todo o dinheiro é virtual, as taxas são fictícias e nada aqui é recomendação de investimento.

## Telas

- Cadastro com validação e quiz de perfil de investidor
- Início, Finanças, Metas e Investir (com o vilão do imposto, o Leão Faminto)
- Trilha do Conhecimento com 9 fases e 4 minijogos
- Perfil com o Pé de Grana, um avatar que cresce e dá frutos
